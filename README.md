SmartPetButton

I was tired of despawned pet corpses or missing live ones causing the macro mechanics to fail with your pet isn't dead!
So i created this small bulletproof button for Summoning, Reviving, and Mending pets built into a tiny addon.
You can alt click it to drag it to anywhere on the screen and to change your keybinds at any time using a simple slash commands.
If you want Ctrl + Page Up Type /spb CTRL-PAGEUP or /spb SHIFT-T for Shift + T or to change to F5: Type /spb F5
To see the help menu: Type /spb or /spb help
(Note: Just like standard keybindings, remember to use capital letters and a hyphen for modifiers like CTRL-, SHIFT-, or ALT-).
